
# Algoritmos Busqueda - Matriz ordenada de precios


Este proyecto corresponde al Protocolo Individual de la Unidad 2, en el cual se implementa y compara dos algortimos de busqueda sobre una matriz bidimensional: Busqueda Ingenua y Staircase Search.

El ejercicio asignado corresponde al numero 16, que trata de una Matriz ordenada de precios, su proposito principal es identiificar las posiciones en las que se aparece un precio determinado, contabilizar sus apariciones y comparar la cantidad de operaciones realizadas por cada algortimo.




## Instrucciones de ejecucion

Clonacion del repositorio de Github

```bash
  git clone https://github.com/BPEINADOM/AlgoritmosBusqueda_ED.git
```

Ubicacion del directorio del repositorio

```bash
  cd algoritmobusqueda/src/main/java/co/edu/udec
```

Ejecucion del proyecto

```bash
  javac MatrizPrecios.java
  java MatrizPrecios
```
